# 准点交班

口腔颌面头颈肿瘤科院内交班侧边应用 MVP。

项目用两个入口演示真实产品关系：医生仍在医院原有电子病历中书写病历；点击“一键导入交班”后，独立的“准点交班助手”按固定模板带入患者信息，并提取“目前病情”和“需要注意的病情”。医生逐人检查、修改和确认后，统一打印为一份连续交班清单。

全部患者和诊疗资料均为虚构演示数据，不用于临床决策。

## 当前演示

- `/`：模拟医院现有电子病历，仅承担患者病历书写
- `/handoff`：独立准点交班助手，只保留“交班管理”
- 简洁蓝白医院信息系统界面，两个系统视觉一致、职责分开
- 从电子病历一次点击直接导入全部患者交班
- 3 位不同病程阶段的虚构患者：新入院、术前、手术当日术后
- 患者卡片进入病历书写或交班核对详情
- 可持续追加的动态病历时间线，长住院患者可有数十篇文书
- 未书写文书预填科室框架，医生可直接补写
- 每篇文书都可修改正文、重命名标题和二次确认删除
- 病历结构参考用户提供的口腔舌癌住院病历范例
- 一键生成全病区交班，无需逐人复制粘贴
- DeepSeek 单患者结构化提取，三位患者有限并行
- 七项交班模板：五项患者基本信息 + 两项 AI 病情提取
- 缺失字段留空、原文证据、医生修改与逐人确认
- 按床位顺序合并打印，一位患者一个段落
- `/board` 保留旧版病区交班实验模式

```text
07床 梁先生  右舌缘鳞状细胞癌        明日手术

```

## 本地运行

```bash
npm install
cp .env.example .env.local
npm run dev -- --port 3210
```

打开：

- 电子病历演示：[http://localhost:3210](http://localhost:3210)
- 准点交班助手：[http://localhost:3210/handoff](http://localhost:3210/handoff)

DeepSeek 配置：

```bash
DEEPSEEK_API_KEY=your_api_key
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-v4-flash
DEEPSEEK_TIMEOUT_MS=35000
```

没有密钥时使用虚构演示结果；模型失败时使用明确标注的演示兜底。密钥仅在服务端读取。真实医疗数据不得未经医院评估就发送至公网模型。
