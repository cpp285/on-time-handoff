# 准点交班

口腔颌面头颈肿瘤科电子病历交班 MVP。

医生在“病史”模块按患者卡片进入分阶段文书书写区，完成全病区病历后点击“一键生成全病区交班”；“交班”模块保持相同患者顺序，医生逐人核对、修改和补充，最后统一打印为一份连续交班清单，每位患者只占一个段落。

全部患者和诊疗资料均为虚构演示数据，不用于临床决策。

## 当前演示

- 口腔颌面头颈肿瘤科工作台
- 左侧“病史 / 交班”两个一级模块
- 5 位不同病程阶段的虚构患者
- 患者卡片进入病历书写或交班核对详情
- 可持续追加的动态病历时间线，长住院患者可有数十篇文书
- 未书写文书预填科室框架，医生可直接补写
- 每篇文书都可修改正文、重命名标题和二次确认删除
- 病历结构参考用户提供的口腔舌癌住院病历范例
- DeepSeek 单患者结构化提取，五位患者有限并行
- 缺失字段留空、原文证据、医生补充与逐人确认
- 按床位顺序合并打印，一位患者一个段落
- `/board` 保留旧版病区交班实验模式

## 本地运行

```bash
npm install
cp .env.example .env.local
npm run dev -- --port 3210
```

打开 [http://localhost:3210](http://localhost:3210)。

DeepSeek 配置：

```bash
DEEPSEEK_API_KEY=your_api_key
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-v4-flash
DEEPSEEK_TIMEOUT_MS=35000
```

没有密钥时使用虚构演示结果；模型失败时使用明确标注的演示兜底。密钥仅在服务端读取。真实医疗数据不得未经医院评估就发送至公网模型。
